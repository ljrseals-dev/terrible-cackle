# FAQ

**Is this a finished synthesizer?**  
No. It is a reusable DSP foundation and a JUCE starter.

**Is this related to the book *CMOS RF and mm-Wave Transceivers and Synthesizers*?**  
The project is inspired by selected engineering principles (oscillator stability, quadrature, PLLs, frequency division) discussed in that literature. It is an independent audio software project and does not reproduce any copyrighted material.

**Does it require the internet?**  
No. Completely offline.

**Is the PLL a real RF PLL?**  
No. It is a simplified musical phase tracker inspired by the same control principles.

**Can I use it commercially?**  
Yes — MIT license.

**Where is the full UI?**  
A functional cosmic-themed editor is included. Further visual polish is planned.
